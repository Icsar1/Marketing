# Web-приложение для медиапланов Яндекс Директа

Приложение формирует медиаплан в PDF по описанию ниши:
- собирает список поисковых фраз через публичные подсказки Яндекса (как приближение Wordstat);
- оценивает частотность и стоимость клика (CPC) по каждой фразе;
- оформляет итог в PDF (таблица, сводные метрики, примечания).

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Открыть: `http://localhost:8000`

## Маршруты

- `GET /` — веб-форма генерации медиаплана.
- `POST /` — генерация и скачивание PDF.
- `POST /webhook/tilda` — webhook для Tilda-форм.

## Подключение Tilda Webhook (по официальным требованиям)

1. В Tilda: **Настройки сайта → Формы → Webhook**.
2. Укажите URL обработчика: `https://your-domain/webhook/tilda`.
3. Сохраните подключение.

Сразу после подключения Tilda отправляет тестовый POST с телом `test=test` и ожидает **код `200 OK`**.
В приложении это учтено: endpoint `/webhook/tilda` отвечает строкой `ok` и статусом `200`.

### Важные требования Tilda

- webhook должен быть доступен по **HTTPS**;
- webhook должен ответить примерно в течение **5 секунд**;
- если не удалось отправить с первого раза, Tilda выполняет повторные попытки.

Поэтому обработчик `/webhook/tilda` сделан максимально лёгким и быстрым: принимает form/json и сразу возвращает `ok`.

### Что именно приходит от Tilda

- поля формы (`Name`, `Email`, `Phone` и т.д., либо custom names);
- служебные поля, например `tranid`, `formid`;
- опционально поле `COOKIES` (если включена отправка Cookie в настройках Tilda).

В коде обработчик принимает как `application/x-www-form-urlencoded`, так и JSON payload.

## Ограничения

- Прямой программный доступ к Wordstat и к странице прогнозатора `advancedForecast` в Яндекс Директе обычно требует авторизацию и может ограничиваться капчей/антиботом.
- Поэтому в текущей версии реализован устойчивый fallback: публичные подсказки + оценочная модель CPC.
- Перед реальным запуском кампаний рекомендуется вручную проверить прогноз в кабинете Яндекс Директа.

## Чистый перенос проекта в другую папку на VPS (без следов старого проекта)

Если в `/root/opt/yandex_site_checker` раньше были файлы другого проекта, используйте скрипт зеркального деплоя:

```bash
./scripts/deploy_clean_to_vps.sh /root/opt/yandex_site_checker
```

Что делает скрипт:
- копирует **только текущий проект** в целевую папку;
- удаляет лишние старые файлы в целевой папке (`rsync --delete`);
- не переносит `.git`, `.venv`, кеши;
- пересоздаёт `.venv` и ставит зависимости из `requirements.txt`.

После этого от старого проекта в целевом каталоге не останется файлов.
